# Nicho

Nicho is a toolkit for YouTube creators, designed to help them crush faceless YouTube. It consists of a website and a Chrome extension, both of which are designed to provide creators with the tools they need to succeed.

## Website

The Nicho website is a landing page that provides an overview of the Nicho toolkit. It includes the following sections:

*   **Hero Banner:** A hero banner with the slogan "Crush faceless YouTube with Nicho".
*   **Tools:** A list of the tools available in the Nicho toolkit, including the Nicho Faceless Course, the Nicho Niche Finder, and the Nicho Chrome Extension.
*   **Testimonials:** A section with testimonials from happy users.
*   **FAQ:** A section with frequently asked questions about the Nicho toolkit.

## Chrome Extension

The Nicho Chrome Extension is a powerful tool that provides creators with a wide range of features to help them research videos and channels, automate their workflow, and gain valuable insights. The extension includes the following features:

*   **Similar Channels:** Find and display similar channels with stats.
*   **Channel Analytics:** Show average views, subscriber count, revenue estimate, etc.
*   **Combined Analytics:** A dashboard where you can enter multiple channel URLs and see combined analytics for all of them.
*   **Filters:** A filter panel to filter results on YouTube's search, home, and subscription pages.
*   **Thumbnail Tools:** Preview and download thumbnails on video search results.
*   **Screenshot Tools:** Capture high-quality screenshots of videos and of individual frames.
*   **Transcripts:** Make video transcripts copyable/selectable.
*   **Comment Sentiment:** Analyze comment sentiment on a video page.
*   **Revenue/Profit:** Calculate and display estimated net profit in the channel dashboard.
*   **Audience Data:** Show a channel's average views and demographic breakdown.
*   **Monetization Status:** Show if a channel is monetized.
*   **Swipe File:** Save any video or channel to a "Swipe File" for later.
*   **Ad Placer:** Automatically insert mid-roll ads in uploaded videos.
*   **Thumbnail/Title Tester:** A/B test thumbnails and titles on the YouTube homepage.
*   **Shorts Analytics:** Show detailed analytics for Shorts videos when browsing Shorts.
*   **Similar Videos:** List similar videos to the one being watched.
*   **Forecast & Top Content:** Forecast channel growth and list top-performing content across channels.
